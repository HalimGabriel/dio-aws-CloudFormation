# AWS CloudFormation - Implementando sua Primeira Stack | DIO

Repositório desenvolvido para o desafio da **Formação AWS Cloud Foundations** da **Digital Innovation One (DIO)**, com o objetivo de documentar os conceitos e a prática de criação da primeira **Stack** utilizando o **AWS CloudFormation**.

## O que é o AWS CloudFormation?

O **AWS CloudFormation** é um serviço de Infraestrutura como Código (Infrastructure as Code - IaC) da AWS que permite criar, configurar e gerenciar recursos da nuvem por meio de arquivos de template.

Com ele, é possível automatizar a criação de ambientes completos de forma padronizada, reproduzível e segura.

## O que aprendi neste desafio

Durante a realização do laboratório, foram abordados os seguintes conceitos:

- Conceito de Infraestrutura como Código (IaC).
- O que são **Stacks** no AWS CloudFormation.
- Estrutura de um template CloudFormation.
- Criação e implantação de uma Stack na AWS.
- Gerenciamento e atualização de recursos através das Stacks.
- Exclusão de recursos de forma automatizada.

## Estrutura de um Template CloudFormation

Um template CloudFormation é composto por seções que descrevem a infraestrutura.

| Seção | Função |
|-------|--------|
| `AWSTemplateFormatVersion` | Define a versão do template. |
| `Description` | Descreve o objetivo da infraestrutura. |
| `Resources` | Define os recursos que serão criados. |
| `Outputs` | Exibe informações geradas após a criação da Stack. |

## Etapas realizadas no laboratório

1. Acesso ao serviço **AWS CloudFormation**.
2. Criação de uma nova Stack.
3. Upload do template disponibilizado no laboratório.
4. Validação das configurações.
5. Criação da Stack.
6. Acompanhamento dos eventos de implantação.
7. Verificação dos recursos criados.
8. Exclusão da Stack para evitar consumo desnecessário de recursos.

## Benefícios do AWS CloudFormation

- Automação da infraestrutura.
- Padronização de ambientes.
- Reutilização de templates.
- Controle de versão da infraestrutura.
- Facilidade para atualizar e remover recursos.
